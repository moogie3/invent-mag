Introduction

Invent-MAG exposes a deliberately small REST API covering authentication, tenant discovery, CMS content, marketing plan pricing, payment confirmations, and Midtrans webhooks. All other functionality is served by the session-authenticated web admin panel (/admin/*) and is intentionally not part of the API.

Base URL: http://127.0.0.1.nip.io 
This documentation aims to provide all the information you need to work with our API.

<aside>As you scroll, you'll see code examples for working with the API in different programming languages in the dark area to the right (or as part of the content on mobile).
You can switch the language used with the tabs at the top right (or from the nav menu at the top left on mobile).</aside>

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {YOUR_API_TOKEN}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

You can retrieve your token by visiting your dashboard and clicking Generate API token.

Authentication

Public registration, login, and tenant lookup, plus token refresh for authenticated clients.

Log in and receive an API token.

Authenticates the user with email and password and returns a Sanctum bearer token for authenticated API calls. Rate-limited to 5 requests per minute per IP.

Example request:
curl --request POST \
    "http://127.0.0.1.nip.io/api/login" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"email\": \"qkunze@example.com\",
    \"password\": \"O[2UZ5ij-e\\/dl4m{o,\"
}"

const url = new URL(
    "http://127.0.0.1.nip.io/api/login"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "email": "qkunze@example.com",
    "password": "O[2UZ5ij-e\/dl4m{o,"
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());

Example response (200, success):


{
    "token": "1|abcdefghijklmnopqrstuvwxyz",
    "token_type": "Bearer"
}

Example response (401, invalid credentials):


{

Webhooks

Midtrans payment notification endpoints.

Receives Midtrans transaction notifications, verifies the SHA-512 signature, and updates the matching subscription order (paid on capture/settlement, failed on cancel/deny/expire). Configure this URL in the Midtrans dashboard; POST /api/webhook is a fallback alias for misconfigured dashboards.
