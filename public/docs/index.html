Introduction

Invent-MAG exposes a deliberately small REST API covering authentication, CMS content, and supporting endpoints. All other functionality is served by the session-authenticated web admin panel (/admin/*) and is intentionally not part of the API.

Base URL: http://127.0.0.1.nip.io 
This documentation aims to provide all the information you need to work with our API.

<aside>As you scroll, you'll see code examples for working with the API in different programming languages in the dark area to the right (or as part of the content on mobile).
You can switch the language used with the tabs at the top right (or from the nav menu at the top left on mobile).</aside>

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {YOUR_API_TOKEN}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

You can retrieve your token by visiting your dashboard and clicking Generate API token.

Authentication

Public registration, login, and tenant lookup, plus token refresh for authenticated clients.

Log in and receive an API token.

Authenticates the user with email and password and returns a Sanctum bearer token for authenticated API calls. Rate-limited to 5 requests per minute per IP.

Example request:
curl --request POST \
    "http://127.0.0.1.nip.io/api/login" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"email\": \"qkunze@example.com\",
    \"password\": \"O[2UZ5ij-e\\/dl4m{o,\"
}"

const url = new URL(
    "http://127.0.0.1.nip.io/api/login"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "email": "qkunze@example.com",
    "password": "O[2UZ5ij-e\/dl4m{o,"
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());

Example response (200, success):


{
    "token": "1|abcdefghijklmnopqrstuvwxyz",
    "token_type": "Bearer"
}

Example response (401, invalid credentials):


{
    "message": "Invalid login details"
}

Refresh the current API token.

requires authentication

Revokes the current token and issues a new one with a one-day expiry. Call this with the token you want to replace.

Example request:
curl --request POST \
    "http://127.0.0.1.nip.io/api/v1/refresh-token" \
    --header "Authorization: Bearer {YOUR_API_TOKEN}" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json"
const url = new URL(
    "http://127.0.0.1.nip.io/api/v1/refresh-token"
);

const headers = {
    "Authorization": "Bearer {YOUR_API_TOKEN}",
    "Content-Type": "application/json",
    "Accept": "application/json",
};


fetch(url, {
    method: "POST",
    headers,
}).then(response => response.json());

Example response (200, success):


{
    "token": "2|abcdefghijklmnopqrstuvwxyz",
    "expires_at": "2026-08-13T09:00:00.000000Z"
}

CMS Content

Public landing-page content served to the Astro marketing site at build time.

Get marketing-site CMS content.

Returns the landing-page copy (hero, features, pricing, CTA, footer) served to the Astro marketing site at build time. Responses are cached for 1 hour.

    --header "Content-Type: application/json" \

);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",

    method: "GET",

Contact

Marketing-site contact form submission.

Handle the marketing-site contact form submission.

Validates the form, passes the built-in honeypot (botcheck must stay empty), and emails the platform contact address.

Example request:
curl --request POST \
    "http://127.0.0.1.nip.io/api/contact" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"name\": \"consequatur\",
    \"email\": \"qkunze@example.com\",
    \"company\": \"consequatur\",
    \"topic\": \"support\",
    \"message\": \"consequatur\",
    \"botcheck\": \"consequatur\"
}"

const url = new URL(
    "http://127.0.0.1.nip.io/api/contact"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "name": "consequatur",
    "email": "qkunze@example.com",
    "company": "consequatur",
    "topic": "support",
    "message": "consequatur",
    "botcheck": "consequatur"
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());

Example response (200, success):


{
    "success": true,
    "message": "Message sent successfully!"
}

Example response (422, validation error):


{
    "success": false,
    "message": "Validation failed",
    "errors": {
        "email": [
            "The email field must be a valid email address."
        ]
    }
}

Example response (500, mail failure):


{
    "success": false,
    "message": "Failed to send message. Please try again."
}

The selected topic. Example: support

  • demo

  • other
